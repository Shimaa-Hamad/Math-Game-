# Math Game

🎮 A simple console-based math quiz game built with C++.  
The game generates math questions based on your selected difficulty level and operation type, then checks your answers and shows your final score.

## Features

- Select number of questions (1 to 10)
- Choose difficulty level:
  - Easy
  - Medium
  - Hard
  - Mixed
- Choose operation type:
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - Mixed operations
- Colored feedback for correct/wrong answers
- Final result summary after the quiz
